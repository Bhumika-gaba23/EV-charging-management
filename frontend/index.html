Google Maps setup steps
  1. Create a Google Cloud project and enable billing.
  2. Enable Maps JavaScript API and Places API (New).
  3. Create an API key restricted to websites. Allow http://127.0.0.1:4173/* and your deployed domain.
  4. Restrict the key to the two APIs above and set usage quotas.
  5. Enter the key here, enable Maps, then choose Real stations in Stations.
